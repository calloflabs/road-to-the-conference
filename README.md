세션 시작 20분 전. 교수님은 조수석에서 슬라이드를 바꾸고 계시고 운전대는 당신 손에 있다. 거위 떼와 학과장님이 도로를 막고 있어도 어쩔 수 없다. 학회장까지 가야 한다.
